## 2. Completed Work

### 定位到端到端实验的配置错误

- 对比了 Baseline 和 SAPR-E e2e 的 `intermediate_data.json`（30 条）
- 发现 30/30 条的完整 thought 序列 byte-level 完全一致
- 追踪到 ReasonRAG batch pipeline 的路由逻辑：flag="None" → answer_generation_prompt（无文档）
- 确认模型从不生成 `"So the next query is..."`（0/143 steps）
- **根因**：实验配置 `max_tokens=32`，ReasonRAG 原始为 `256`，模型每步被截断无法输出结论标记

### 架构分析

- 对比了 ReasonRAG tree mode (MCTS) 和 batch mode 的路由差异
- Tree mode：状态机驱动，默认强制注入文档
- Batch mode：模型驱动，依赖模型主动请求检索
- batch mode 在 max_tokens=256 下设计合理，32 token 破坏了前提
