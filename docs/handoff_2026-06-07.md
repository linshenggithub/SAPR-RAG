## 3. 下一步：两条路任选一

### 路线 A：等开发机扩容完成，本地推理（推荐）

扩容流程走完后（用户已发起申请），盘空间预期 → 250GB+。然后：

```bash
# Step 1: 重下 Qwen base
huggingface-cli download Qwen/Qwen2.5-7B-Instruct \
    --local-dir 03_sapr_rag/models/Qwen2.5-7B-Instruct

# Step 2: 验证 index 完整性（双副本）
ls -la SAPR-RAG/data/index/bge_extended_Flat.index
# 期望大小: 68,667,479,085 bytes

# Step 3: 跑 sanity 50 条
python 03_sapr_rag/scripts/eval/agent_infer.py \
    --backend transformers \
    --base 03_sapr_rag/models/Qwen2.5-7B-Instruct \
    --lora 03_sapr_rag/saves/qwen2_5_7b/lora/sft/checkpoint-1650 \
    --index SAPR-RAG/data/index/bge_extended_Flat.index \
    --corpus SAPR-RAG/data/corpus/wiki18_extended.jsonl \
    --bge models/bge-base-en-v1.5 \
    --queries data/raw/hotpotqa/dev.jsonl \
    --limit 50 \
    --out 04_experiments/runs/hotpot_dev_sanity50.jsonl

# Step 4: 跑 score
python 03_sapr_rag/scripts/eval/score.py \
    --in 04_experiments/runs/hotpot_dev_sanity50.jsonl
```
