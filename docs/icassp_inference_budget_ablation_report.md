# SAPR-RAG ICASSP 推理预算消融实验报告

日期：2026-09-23。状态：**全量完成，协议校验通过**。

## 1. 实验范围

本实验固定 SAPR-RAG Full（C/E16）`checkpoint-1000`，只改变推理阶段的最大检索
次数与单次检索宽度：

- 深度消融：`max_searches = 0...7`，固定 `top_k=3`；
- 宽度消融：`top_k = 1/3/5`，固定 `max_searches=5`；
- 数据集：HotpotQA、2WikiMultiHopQA、MuSiQue 完整 dev 集；
- 10 个唯一配置，30 个数据集运行，共 223,980 个 question-config 样本；
- 达到检索预算后使用 answer-only system prompt 和 assistant prefill 强制最终回答；
- 配对 bootstrap 使用 10,000 次分层重采样，宏平均为三个数据集的非加权平均。

相对预注册默认点 S5-K3：

- S7-K3 的宏 F1 增加 0.0047，95% CI `[0.0016, 0.0080]`，`p=0.0036`；
- S6-K3 的宏 F1 增加 0.0026，95% CI `[-0.0005, 0.0058]`，`p=0.1022`；
- S5-K3 相比 S4-K3 增加 0.0145，且置信区间完全大于 0。

大部分质量收益集中在 0 到 3 次检索；S4、S5 仍有稳定收益，S5 之后进入明显平台期。
尽管大样本使 S7 相对 S5 的微小增益达到显著，S6-S5 与 S7-S6 均不显著。因而 S5
仍是合理的预注册质量—成本折中点，不应事后用 S7 替换论文默认点。

配对 bootstrap：

| 比较 | Delta EM | Delta F1 | Delta Cover-EM | F1 95% CI | 双侧 p 值 |
|---|---:|---:|---:|---:|---:|
| K1 - K3 | -0.0479 | -0.0505 | -0.0528 | [-0.0560, -0.0450] | 0.0002 |

K5 在三个数据集上都提高 F1，并同时降低平均逻辑检索数、实际 RPC 数、强制回答率和
重复 query 率。该结果支持“更宽的单次检索改善证据覆盖，并减少后续补充检索”的解释。
但延迟来自独立运行的批次摊销值，不能据此断言 K5 的真实在线尾延迟低于 K3。

## 6. 行为与成本

- 总逻辑检索 RPC：424,542；
- 从首次启动到最后配置完成：42,118 秒，即 11 小时 41 分 58 秒；
- 十个配置累计 GPU 时间：65.9164 GPU 小时；
- 按总墙钟计算的检索吞吐：10.0798 RPC/s；
- GPU0 检索服务峰值显存：68,711 MiB，峰值利用率 97%；
- GPU1-7 rollout 峰值显存：84,099 MiB/卡，峰值利用率 100%；
- 深度从 S5 增至 S7 时，平均实际 RPC 仅从 2.371 增至 2.396，说明大多数样本会提前
  停止；与此同时重复 query 率从 7.53% 增至 8.95%，额外预算的边际效率下降。

## 7. 执行记录与异常处理

正式运行在 worker4300716 上完成。GPU0 部署独立 Python 环境的检索服务，GPU1-7
部署七个独立 rollout 服务；较早完成的 GPU 动态补位运行 S7-K3、S5-K1、S5-K5。

动态启动 S7 时，`mlx worker login` 的远程命令被重试执行两次，产生两个同端口实例。
失败副本触发启动期 OOM，两个客户端还曾以相同 UUID 并发请求。为避免任何轨迹状态
污染，当时生成的 128 条 S7 中间结果全部弃用并移出正式目录，随后使用原子启动锁从
第 0 条单实例重跑。正式 S7 结果共 22,398 条，退出码为 0，校验无错误。诊断产物位于：

```text
data/eval_results/
icassp_inference_budget_full_ckpt1000_20260922_incidents/
```

自动汇总首次因原主编排器被暂停、manifest 缺少 `completed_at` 而失败。汇总器现会在
该字段缺失时取十个配置 `runtime.tsv` 的最晚完成时间，并在运行清单标记
`completed_at_source=max_config_runtime`。修复后 10,000 次 bootstrap 完整重跑成功。

## 9. 论文结论边界

1. 检索对该 checkpoint 至关重要：S5-K3 相比闭卷 S0-K3 的宏 F1 提高 0.2566。
2. 最大检索次数的主要收益集中在前三次，S5 是稳定的折中点，S5 之后边际收益很小。
3. 在固定五次预算下，K5 显著优于 K3，K1 显著劣于 K3；宽度的影响大于 S5 之后继续
   增加深度。
4. 强制最终回答协议将所有配置的回答率统一为 100%，消除了旧截断计零造成的比较偏差。
5. 本实验只刻画固定 C/E16 checkpoint 的推理预算敏感性，不能证明 GRPO、Query OPSD
   或 Answer OPSD 各训练组件的独立贡献。
